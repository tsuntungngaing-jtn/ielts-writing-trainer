# 评分依据与边界

## 使用官方资料

公共标准入口：
- [IELTS Writing Band Descriptors](https://ielts.org/cdn/Guides/ielts-writing-band-descriptors.pdf)
- [IELTS scoring in detail](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail)

进行完整估分时，优先读取可用的官方描述符。无法联网或无法读取时明确“未重新核对官方描述符，本次为暂定训练反馈”；不要捏造引用或声称已经校准。用户明确不联网则遵从。官方标准优先于社区 skill 和本文件的教学建议。

每篇任务分别看 TA（Task 1）或 TR（Task 2）、CC、LR、GRA，四项等权。完整 Writing 中 Task 2 权重为 Task 1 的两倍。单篇不能代表整个 Writing。

## 观察什么

- Academic Task 1：核对图中对象、时间、单位、变化及重要比较；overview 与细节是否匹配；不能编造数据或因果解释。
- General Training Task 1：写信对象和目的、所有要点、相应语气及格式。不能套用图表 overview 要求。
- Task 2：题目各部分、论点与立场、展开和支持是否回应题意。
- CC：思路推进、分段、指代和衔接是否帮助读者。
- LR：词义、搭配、拼写和适当范围；不能按“大词”数量评分。
- GRA：实际句法范围、错误频率及沟通影响；不能按复杂句数量评分。

Task 1 最少 150 词，Task 2 最少 250 词。字数不足须说明内容和语言证据受限，不发明“少一个词扣半分”等扣分公式。固定段数、词汇重复次数和连接词数量只是观察线索，不是官方阈值。

## 出分方式

对照整档描述符，给最有依据的档位或相邻档区间。每项都引用学生原文证据并解释差距。缺材料就留空；不可只因用户要求精确而编造分数。

若所有维度可评，可提供单篇训练估计，通常以半分或区间表达。两篇都充分可评时，可按 (Task 1 + 2 × Task 2) / 3 展示加权训练参考。不要把雅思四科总分的舍入规则冒充内部写作评分程序。

禁止把以下说法当作规则：
- 漏一个问题固定降至某分。
- 生词替换越多，LR 越高。
- 必须四段、不能有条件赞同。
- 改写后“稳定 8 分”或练习若干天保证提分。

## 校准

用户要求校准时，选择有官方考官评语的样本；先独立判断，再对照官方已公布的分数与评语。若只公布总体分，不虚构四项分。记录样本来源、模型估计、官方分和差异原因。一次符合不证明准确率，也不把社区作者的成绩当成技能验证。
