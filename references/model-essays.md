# 局部改写与目标分范文

设计参考（未复制第三方全文提示词或题库）：
- AaronL725/ielts-writing-review-skills：有稿时局部改写 + 完整范文
- JacobYixi/ielts-writing：按 4.0–9.0 目标分生成示范

官方描述符始终优先。范文是教学示范，不是官方样卷，也不承诺考场同分。

## 何时启用

| 用户意图 | 产出 |
| --- | --- |
| 普通训练（有稿） | 先诊断 + 自行修改；用户完成后再给局部对照 |
| 直接精批 / 全部改好 / 范文 / 示范 / 融合范文 | **跳过等待**；一次给出诊断 + 局部改写 + 完整范文 |
| 只有题目、要范文 | 确认 Task 1/2 与目标分（未指定则 Task 2 默认 **8.0**，Task 1 默认 **7.5**）后生成 |
| 指定目标分 4.0–9.0 | 语言与展开须贴近该档，**不得明显高出目标档** |

## 局部改写（有学生稿时）

- 默认目标：**以 Band 7.5 为目标风格**（正式、自然，不过度堆砌成 9 分腔；实际得分不保证）。
- 单位：问题局部用**逐句**；逻辑/段落结构问题用**整段**。
- 保留学生立场与有效论据；离题处在改写中拉回题目。
- 格式：原文｜7.5 改写｜理由（维度）。
- 每次完整精批至少覆盖 **2 个整段或 4 个关键句**；用户要“更长示范”时，对全部主体段都给整段改写。

## 完整范文长度与结构

优先满足“更长、可学”的示范，而不是最短及格篇幅。

### Task 2

| 模式 | 目标分默认 | 结构 | 词数 |
| --- | --- | --- | --- |
| 批改配套范文（有稿） | **8.0** | 四段：开头 + 主体×2 + 结尾（`In conclusion` 起句）；若学生有三条清晰理由且都扣题，可用 **五段**（主体×3）以免削掉其思路 | **300–360**（需要更长时可到约 400，须仍紧扣题目） |
| 仅题目生成 | 用户指定，默认 8.0 | 7.0 以下：四段；**7.5+** 可用五段（第三主体或让步段） | 250 起；**7.5+ 默认 300–360** |
| 低分校准示范 | 用户指定 4.0–6.0 | 按目标档故意限制词汇/语法/展开 | 满足最低词数即可 |

立场：学生稿扣题且可辩护时，**保留其主立场**；修正错误逻辑与离题部分。

必须回应题目限定词（如 *best way*、*to what extent*）：不同意“唯一最佳”时，简要对比其他可行方案。

### Task 1（Academic）

| 模式 | 默认目标 | 结构 | 词数 |
| --- | --- | --- | --- |
| 批改配套 / 范文 | **7.5–8.0** | 开头 + **overview** + 细节×2 | **180–220**（更长示范可到约 240） |
| 仅题目生成 | 用户指定 | 同上；缺 overview 不得标为 6+ 示范 | ≥150；高分档用 180+ |

## 目标分校准（生成时）

生成前重读 [assessment.md](assessment.md) 与可用的官方描述符。按档调节，不“升档注水”：

| 区间 | 控制要点 |
| --- | --- |
| 4.0–5.5 | 简单词、简单句为主、展开有限、可有自然错误；勿写成中高级范文 |
| 6.0–6.5 | 回应完整、段落清楚、词汇够用、复杂句有但仍有可控小错 |
| 7.0–7.5 | 展开充分、衔接灵活、搭配较准、多数句子无硬伤 |
| 8.0 | 立场清晰且充分延伸、衔接顺畅、话题词汇灵活、语法大体无误；像扎实 8 分教师范文，**不要**写成炫耀式 9 分 |
| 8.5–9.0 | 仅在用户明确要求时；更精炼、更自然，仍避免空泛华丽 |

标注：`draft_kind: model`；写明 `target_band` 与 `score_source: coach_estimate`（示范目标，非官方分）。

## 精批 + 范文交付顺序

1. 四维估分（评**原文**，不评范文）
2. 三大瓶颈（短）
3. 局部 7.5 改写（加长：尽量覆盖各主体段）
4. 完整目标分范文（加长词数按上表）
5. 可选：一句“范文用了你原文的哪些论点”
6. 短迁移练习（除非用户只要范文）

不要把范文冒充学生已达到的水平。归档时独立稿与 model 分条记录。
